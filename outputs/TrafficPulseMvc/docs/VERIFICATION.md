## מה לא אומת

- מנוע Docker החזיר permission denied ל־named pipe. לא הופעלו containers ולכן מסלול TomTom → Kafka → MySQL → Web לא נבדק בפועל.
- לא הוגדר מפתח TomTom אמיתי; גם מפת TomTom החיה לא אומתה.
- בדיקות HTTP נחסמו בגישה ל־socket המקומי בסביבת ההרצה. כלי הדפדפן נכשל באתחול kernel assets. לכן בדיקות מסכים בדפדפן, כניסה/הרשמה, פעולות אדמין, התרעות ומועדפים דרך HTTP, ומראה desktop/mobile עדיין דורשות הרצה מקומית. כללי CSS למובייל קיימים; אין טענה שנבדקו חזותית.
- בהפעלה עם נתוני Demo קיימים התקבלה שגיאת הרשאה בהחלפת קובץ. בספריית נתונים חדשה האתר עלה; קובצי המשתמש הקיימים לא נמחקו. במידת הצורך מגדירים `App__DataPath` לתיקייה חדשה שניתנת לכתיבה.
- הבדיקה הראשונה בתיקיית Temp נחסמה בהרשאות. הרצה עם TEMP ו־TMP בתוך `.data/test-temp` עברה את כל 24 הבדיקות.
